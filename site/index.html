How It Works

Deploy alongside your existing Podsync container in under a minute.

1

Mount Config & Docker Socket

Share your ./config directory and /var/run/docker.sock with the podsync-manager container so it can manage config.toml atomically and inspect Podsync.

2

Configure Feeds & Preview Filters

Add YouTube, SoundCloud, Vimeo, or Twitch URLs, tune retention and duration rules, and simulate episode filtering before saving.

3

Review Diff & Apply Restart

Compare your staged changes in the Diff modal, click Apply & Restart, and watch live SSE logs as Podsync syncs new episodes.

Installation & Quick Start

Choose Docker Compose, Docker CLI, or build the single Go binary from source.

Docker Compose (Recommended) 
services:
  podsync:
    image: mxpv/podsync:latest
    container_name: podsync
    restart: unless-stopped
    volumes:
      - ./config:/app/config
      - ./data:/app/data

  podsync-manager:
    image: ghcr.io/badugisoft/podsync-manager:latest
    container_name: podsync-manager
    restart: unless-stopped
    ports:
      - "3000:3000"
    volumes:
      - ./config:/app/config
      - /var/run/docker.sock:/var/run/docker.sock
    environment:
      - PODSYNC_CONFIG_PATH=/app/config/config.toml
      - PODSYNC_CONTAINER_NAME=podsync
      - ADMIN_USERNAME=admin
      - ADMIN_PASSWORD=your_secure_password
Docker Run CLI 
docker run -d \
  --name podsync-manager \
  -p 3000:3000 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v ./config:/app/config \
  -e ADMIN_PASSWORD=your_secure_password \
  ghcr.io/badugisoft/podsync-manager:latest
Local Single-Binary Build (Go + Node.js) 
git clone https://github.com/badugisoft/podsync-manager.git
cd podsync-manager
cp .env.example .env
npm install && npm run build
go build -o podsync-manager ./cmd/server
./podsync-manager

Frequently Asked Questions

Why should I mount the ./config directory instead of config.toml directly?

Mounting the parent directory (-v ./config:/app/config) lets Podsync Manager write temporary files (.tmp), perform atomic renames, and create .bak backups on the same filesystem without EXDEV cross-device errors or stale bind-mount inodes.

Why does Podsync Manager need access to /var/run/docker.sock?

Docker socket access enables real-time container status checks, live SSE log streaming, explicit container restarts after config diff review, and automatic detection of S3 credentials configured on the Podsync container.

How does the YouTube format 18 preset reduce CPU usage and bot blocks?

Format 18 fetches a pre-muxed 360p stream directly from YouTube without server-side ffmpeg re-encoding. Combined with Android client emulation (--extractor-args youtube:player-client=android), it speeds up downloads and avoids rate-limit blocks.

How are S3 credentials and API tokens stored?

S3 keys and YouTube/Vimeo/SoundCloud/Twitch tokens can be injected via environment variables and are masked in the UI. Podsync Manager never transmits credentials outside your host and the configured S3 endpoint.

Does Podsync Manager collect any telemetry or analytics?

No. Podsync Manager is 100% self-hosted and collects zero telemetry, tracking, or usage analytics.
